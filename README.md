# SoulChat

> Converse com qualquer personagem de IA. A IA pesquisa na Wikipedia e dá vida ao personagem automaticamente.

## ✨ Features

- 🪄 **Geração automática** — digite o nome, a IA pesquisa na Wikipedia e cria personalidade, voz e história
- 💬 **Chat com streaming** — respostas aparecem palavra por palavra em tempo real
- 🎭 **Personagens sugeridos** — Goku, Sherlock, Einstein, Batman, Naruto, Yoda, Tony Stark, Cleópatra
- 🧠 **Personalidade real** — o system prompt faz o personagem agir autenticamente, sem quebrar personagem
- 📝 **Criação manual** — preencha nome, descrição, traços e voz manualmente
- 🌍 **8 idiomas** — PT-BR, EN, ES, FR, DE, IT, JA, ZH-CN
- 💾 **Recentes** — personagens salvos no localStorage pra acesso rápido
- 🎨 **Dark theme** — roxo/rosa profundo, identidade "alma/personagens"
- 📱 **Responsivo** — funciona em mobile e desktop
- 🔒 **100% no navegador** — sem backend, sem servidor

## 🚀 Como usar

1. Abra `index.html` em qualquer navegador
2. Digite o nome de um personagem (ex: "Goku") e clique em "Gerar"
3. A IA pesquisa na Wikipedia e preenche tudo automaticamente
4. Converse com o personagem!

## 🛠️ Tecnologias

- HTML + CSS + JavaScript puro (zero dependências)
- Pollinations AI (API gratuita compatível com OpenAI)
- Wikipedia REST API
- localStorage para recentes
- Single file — um `index.html` faz tudo
